# 手工织锦纹样排版台

直接打开 `index.html` 使用。

## 基础功能
- 网格绘制：点击/拖动填色，单点、十字、小菱形纹样块
- 色线用量统计、重复单元预览、断线风险提示
- 撤销 / 重做（50 步）
- 本地保存（自动保存 + 「保存方案」手动保存）、导出 / 导入 JSON

## 版本审签与差异合并
- **版本分支**：任意版本（含已锁定版本）都可「分支」新建草稿，草稿间形成可追溯的版本树
- **提交审核**：草稿 / 被退回版本可提交审核；审核中版本暂时锁定
- **审签**：须由他人通过或退回（本人不能审批自己的提交）；退回必须填写原因，退回后可修改再提交
- **通过锁定**：通过的版本永久锁定，只能分支出新草稿继续演进
- **版本对比**：任选两版查看格子差异图、变更数量、受影响色线（用量增减）与冲突列表
- **冲突与合并**：两侧相对共同基底都改过的格子记为冲突，须逐项选择目标侧 / 来源侧，冲突未处理完不能合并；普通差异可逐项勾选合并，合并生成新的草稿版本
- **操作记录**：分支、提交、审签、合并均记录人员、时间与详情，记录只增不减、不可清除
- **可追溯还原**：刷新、导出再导入后，版本关系、锁定状态、冲突处理结果与操作记录全部还原；导入采用合并方式，不会丢失已有记录；兼容旧版导出文件（导入为新草稿）

页头顶部可切换「当前人员」身份，用于演示提交人与审签人分离。
